Send a big file from your phone. Straight to theirs.

Pick a file, get a link, send the link however you like. When your friend opens it, the file travels from your phone to theirs. No upload to a cloud, no account, no size limit beyond what your phones can hold.

Get Latchway for Android Read the source on GitHub

How it stays private

The link carries the key. Everything is encrypted on your phone before it leaves and decrypted only on your friend's. You can add a password to the link, approve each download by hand, set the link to expire, or cancel it instantly.

What this server sees

  • The fileNever. It moves phone to phone.
  • The file's name or sizeNever. They're encrypted too.
  • The keyNever. It lives after the # in the link, which browsers don't send to servers.
  • What it does seeThat two phones want to meet, and their addresses, for the few seconds it takes to introduce them.

When phones can't connect directly

Roughly one connection in ten hits a network that won't allow a direct path. Then the encrypted stream is relayed through Cloudflare's TURN service, which can't read it either. Prefer that always, to keep your address private from the other person? Turn on relay-only mode in the app.

Run your own

Everything, including this server, is open source under the GPL. Point the app at your own server from its settings if you'd rather not use this one.
