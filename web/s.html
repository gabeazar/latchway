Open in Latchway Get Latchway

Nothing opened? You need the Latchway app on this phone. Install it, come back to this page and tap Open in Latchway again. The file stays available as long as the sender keeps sharing it.

The Latchway phone app is still in development, and receiving straight from this page is on the way. Today you can receive on any computer with the command-line tool:

go install github.com/gabeazar/latchway/cmd/latchway-receive@latest
latchway-receive 'this link'

This link is incomplete. The part after the # is the key that unlocks the file, and it's missing. Ask the sender to share the link again, ideally by pasting it rather than retyping it.

What happens when you open it

  1. Your device connects to theirs

    Through a brief introduction by latchway.app, which sees that two devices want to meet and nothing else.

  2. The key never leaves you

    Only someone holding this exact link can decrypt the file. The part after the # is never sent to any server.

  3. The file streams across

    Directly from their device to yours, sealed chunk by chunk. If the sender set a password, you'll be asked for it.

Latchway is open source. This page stores nothing about you.
